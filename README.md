# ITVET Turnitin Student Hub

A standalone GitHub Pages website for ITVET students at Otto von Guericke University Magdeburg.

## Contents

- Student assignment-upload guide
- Winter Semester 2026/2027 Turnitin classes
- Previous-semester Turnitin classes
- Searchable course lists
- Direct link to Turnitin My Files

## Publish with GitHub Pages

Create a public GitHub repository, push these files to the `main` branch, and configure GitHub Pages to deploy from the repository root.

The long Turnitin hand-in URLs are intentionally displayed as clear action buttons rather than visible text.
